About This Project

Developed for the NEP 2020 Field Project curriculum at Modern College Shivajinagar.

  • Architecture: Modular multi-page application.
  • Backend: Node.js, Express, SQLite (`better-sqlite3`), Socket.io.
  • Security: JWT token authentication with `bcryptjs` password hashing.
