# Style Rule: No Emojis in Codebase

## Policy
Never use emojis in:
- UI copy, headings, labels, and helper text
- Buttons, chips, tabs, and badges
- Empty states, modals, and tooltips
- Toast notifications and alert banners
- Console logs, logger messages, and test outputs
- Backend templates and API error responses

Unless explicitly requested by the user, all visual iconography must use clean, professional inline SVG icons or standard text tags (e.g. `[INFO]`, `[ERROR]`, `[PASS]`, `[FAIL]`).
This maintains a clean, modern, professional, non-AI-generated appearance throughout the application.
